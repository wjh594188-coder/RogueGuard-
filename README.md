# RogueGuard 安装包仓库

本仓库用于存放 **RogueGuard（反流氓软件）** 各版本的 **安装包（.exe）**。

## 与更新仓库的区别

| 仓库 | 内容 | 用途 |
|---|---|---|
| **本仓库** | 安装包 `.exe` | 手动下载安装 |
| [Version-Update](https://github.com/wjh594188-coder/Version-Update) | 便携版 `.zip` | 程序内自动更新 |

分开存放是为了避免旧版本程序内的更新器把安装包误当成更新包下载。

## 下载

请到 [Releases](../../releases) 页面下载对应版本的安装包。
